## 🔹 Projects Overview
### Project	Tools	Description	Key Insights
| Project                           | Tools                                   | Description                                                                                             | Key Insights                                                                                                                       |
| --------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Superstore Sales Dashboard**    | Excel, Power BI                         | Analyzed 10K+ sales transactions to track KPIs, category/sub-category performance, and regional trends. | Technology category most profitable; high discounts reduce profit margins; West region performs best.                              |
| **Healthcare Claims Analysis**    | SQL, Excel, Power BI                    | Analyzed 1,300+ healthcare claims to identify cost drivers by age, BMI, smoking status, and region.     | Smokers incurred 4x higher claim costs; obese middle-aged adults had highest claims; Southeast had highest obesity-related claims. |
| **Investor Trend Analysis**       | Python, Excel, Power BI                 | Analyzed startup investments to identify top investors, investment trends over time, and funding patterns by startup type and city.     | The analysis reveals notable trends in startup investments, highlighting the sectors that attract the most funding and the investors leading the charge.                                 |
