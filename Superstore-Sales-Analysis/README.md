## 📊 Superstore Sales Dashboard
### 📌 Project Overview

This project analyzes sales performance from the Superstore dataset and provides an interactive dashboard to uncover insights into profits, sales, and customer segments.
The dashboard helps businesses track regional performance, product categories, and customer trends for better decision-making.

### 📂 Dataset

I used the Sample Superstore dataset provided by Tableau.
🔗[ Download Dataset (Kaggle)](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final)

The dataset contains:

13 columns (Order Date, Ship Date, Customer Name, Segment, Country, Region, Category, Sub-Category, Sales, Quantity, Discount, Profit, etc.)

9,994 rows of transaction data.

### ✅ Tasks Performed
#### 1. Data Cleaning & Preparation

Removed duplicates and null values.

Formatted date fields (Order Date & Ship Date).

Ensured correct data types for numeric fields (Sales, Profit, Discount).

Added calculated fields (e.g., Profit Ratio = Profit / Sales).

#### 2. Dashboard Development

KPIs Created:

Total Sales

Total Profit

Profit Margin %

Total Orders

#### Visualizations Added:

📍 Sales by Region (Map)

📊 Sales & Profit by Category & Sub-Category (Bar Chart)

📈 Sales Trend Over Time (Line Chart)

🏆 Top 10 Customers by Sales (Bar Chart)

📦 Ship Mode Performance

Used slicers/filters for Year, Region, and Category for better interactivity.

#### 3. Insights Derived

Technology category contributes the highest profit margin.

Office Supplies has high sales but comparatively lower profit margins.

Central Region performs best in terms of sales, while South Region lags.

Discounts reduce profit margins significantly in certain categories.

#### 🛠️ Tools Used

Power BI – Dashboard creation
